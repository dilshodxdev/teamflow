# SMART maqsadlar

Quyidagilar rejalashtirilgan mezonlar; bajarilgan natija sifatida talqin qilinmasin.

| Maqsad                   | O‘lchov                                                           | Muddat                     |
| ------------------------ | ----------------------------------------------------------------- | -------------------------- |
| Lokal MVPni tayyorlash   | Auth, loyiha, vazifa, jamoa va risk APIlari ishlaydi              | Bir ish kuni yakuni        |
| Ruxsatlarni ta’minlash   | Manager/member/pending oqimlari avtomatik tekshiriladi            | Integratsiyadan oldin      |
| Yagona ishga tushirish   | Root `pnpm dev` 5173 va 4000 portlarini ochadi                    | Topshirishdan oldin        |
| UI va API integratsiyasi | Kirish, CRUD, Kanban va taqvim real SQLite ma’lumotida ishlaydi   | Frontend handoffidan keyin |
| Namoyishga tayyorlash    | Takroriy xavfsiz seed, demo qo‘llanma va boshqaruv hujjatlari bor | Kun yakuni                 |

Ko‘lam besh kishilik bitta jamoa bilan chegaralangan. Har bir maqsad test jurnali yoki amaliy namoyish bilan tasdiqlanadi.
