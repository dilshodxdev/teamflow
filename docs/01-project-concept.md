# TeamFlow loyihasi konsepsiyasi

Urganch davlat universitetining “Dasturiy ta’minot loyihalarini boshqarish” fani uchun besh kishilik jamoaning kichik loyihalarini boshqarish MVPsi.

Muammo: vazifalar, muddatlar, mas’ullar va risklar turli joylarda saqlansa, loyiha holatini ko‘rish qiyinlashadi. Yechim: bitta umumiy jamoa uchun loyiha, vazifa, Kanban, taqvim, jamoa va risklarni yagona ilovada ko‘rsatish.

Asosiy foydalanuvchilar: boshqaruvchi va tasdiqlangan a’zo. Yangi hisob boshqaruvchi tasdiqlaguncha `pending` holatida bo‘ladi. Tasdiqlash elektron pochta egasini tekshirish xizmati emas.

Chegara: lokal kompyuter, React interfeysi, Express REST API va SQLite. Bir nechta tashkilot, real vaqt xabarlari, bulut xizmatlari va mobil ilova MVPga kirmaydi. Namoyish yozuvlari talabalar bajargan ishning isboti emas.
